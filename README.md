# Excel Project Management & Performance Dashboard

## Project Overview
An interactive Excel dashboard designed to manage project tasks, track completion rates, and evaluate customer performance. The workbook combines three dashboards: **Project Tracker, Spider Chart, and Process Tracker**, providing visual insights to support efficient project management and data-driven decision-making.

## Key Features

### 1. Project Tracker
- **Task Management:** Tracks individual projects using interactive checkboxes.
- **Automated Progress Tracking:** Calculates completion rates from 0% to 100%.
- **Deadline Monitoring:** Organizes projects by unique IDs and deadlines.
- **Conditional Formatting:** Highlights project status with color-coded indicators.
- **Interactive Filters:** Filters projects by completion status.

### 2. Spider Chart Dashboard
- **Dynamic Radar Chart:** Compares customer ratings against target scores.
- **Customer Selection:** Allows users to analyze individual customer performance.
- **Performance Evaluation:** Measures six attributes: Plan, Budget, Risk, Comms, Lead, and Time.
- **Target Achievement Rate:** Displays overall performance against predefined targets.
- **Visual Analysis:** Identifies performance gaps and improvement opportunities.

### 3. Process Tracker
- **Interactive Task Checklist:** Tracks individual tasks using checkboxes.
- **Automatic Status Updates:** Displays tasks as Completed or In Progress.
- **Completion Rate Calculation:** Calculates the percentage of completed and remaining tasks.
- **Visual Progress Indicator:** Uses a cylinder-style chart to illustrate overall project completion.
- **Project Monitoring:** Provides a clear overview of renovation project progress and outstanding activities.

## How to Use
1. Open the Excel workbook.
2. Navigate to **Project Tracker** to monitor deadlines, tasks, and completion rates.
3. Use the interactive filters to review projects by status.
4. Open **Spider Chart** and select a customer to compare performance against target scores.
5. Navigate to **Process Tracker** to update task completion using checkboxes.
6. Review the automatically calculated completion percentages and visual progress indicators.

## Project Objective
To build an Excel-based project management and performance monitoring solution that simplifies task tracking, automates progress calculations, and transforms operational data into actionable insights.

## Business Value
- Reduces manual tracking and reporting.
- Improves visibility into project progress and deadlines.
- Supports performance evaluation and gap identification.
- Enhances operational efficiency through interactive visualizations.
- Enables faster, data-driven decision-making.
